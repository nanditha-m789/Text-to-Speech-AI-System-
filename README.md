# 🔊 Text-to-Speech-AI-System

AI project that converts Text and PDF to Speech using Python.

### Project 2 - After AI Resume Screener
Built by Nanditha M

## Features
- app.py: Converts Environment text to speech
- pdf_reader.py: Reads full PDF and speaks (with error handling)
- Works offline

## Tech Stack
Python, pyttsx3, PyPDF2

## How to Run
pip install -r requirements.txt
python app.py
python pdf_reader.py

## Use Case
Helps visually impaired, e-learning
